# 日ノ本帝國 文藝廳 公式情報網（制作初期版）

近代文學・大正浪漫の意匠と、重厚な中央官廳の情報設計を組み合わせた静的サイトです。

## ページ
- `index.html` トップページ
- `about.html` 文藝廳について
- `support.html` 文藝振興・作家支援
- `awards.html` 文藝賞・表彰制度
- `archive.html` 文藝資料室
- `notices.html` 告示・公表資料
- `staff.html` 組織・人事情報
- `links.html` 関連機關・リンク集
- `sitemap.html` サイトマップ

## デザイン
- 臙脂色、象牙色、墨染色、古金色
- 日本語明朝体を中心にした近代文學風のタイポグラフィ
- モバイル対応、キーボードフォーカス、本文へのスキップリンク

## 制作上の方針
文藝廳及び記載した制度・事業は、日ノ本帝國の既存設定に追加するための新規企画案です。既存の人物・作品に未確認の経歴や受賞歴を付与しません。法令・組織・人事・制度の正式設定は、ユーザーの確定設定と照合したうえで確定します。

## 配置
本初期版は既存の `-web-Shikicho` リポジトリ内の `bungeicho/` ディレクトリに追加されています。GitHub Pages の既存サイト配下での公開を想定しています。独立したリポジトリへ分離する場合は、当該ディレクトリの内容を新規リポジトリのルートへ移してください。
