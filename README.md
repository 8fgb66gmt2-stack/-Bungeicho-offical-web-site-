# 日ノ本帝國 文藝廳｜公式情報網

玲瓏時代の日ノ本帝國文藝廳を案内する、GitHub Pages 対応の静的ウェブサイトです。近代文學・大正浪漫の編集意匠と、公的機關にふさわしい情報設計を組み合わせています。

## 公開ページ

| ファイル | 役割 |
| --- | --- |
| \`index.html\` | 文藝廳トップページ・全體索引 |
| \`about.html\` | 文藝廳の概要・理念 |
| \`support.html\` | 文藝振興・作家支援 |
| \`awards.html\` | 文藝賞・表彰制度 |
| \`archive.html\` | 文藝資料室・分類・検索 |
| \`jinbutsuroku.html\` | 文學・藝術人物録・頭文字索引 |
| \`notices.html\` | 告示・公表資料 |
| \`staff.html\` | 組織・人事情報 |
| \`links.html\` | 關係機關・外部リンク |
| \`sitemap.html\` | 利用者向けサイトマップ |
| \`sitemap.xml\` | 検索エンジン向けサイトマップ |

## フロントエンド構成

- \`style.css\`：基本レイアウト・共通構造
- \`literary.css\`：文藝廳の基本意匠・下層ページ
- \`aesthetic.css\`：トップページの編集デザインと章の表示演出
- \`jinbutsuroku.css\`：人物録のレイアウト
- \`reirou.css\`：共通デザイントークン、玲瓏浪漫の仕上げ、レスポンシブ調整
- \`site.js\`：共通ナビゲーション・全體索引ダイアログ
- \`aesthetic.js\`：トップページの軽量な表示演出
- \`jinbutsuroku.js\`：人物録の検索・分類フィルター・頭文字索引
- \`reirou.js\`：栞、文字サイズ調整、時報、暦、ページ遷移、資料室検索など
- \`monsho.svg\`：文藝廳の印章（favicon）

JavaScript は外部ライブラリを必要としません。閲覧補助の栞は使用中のブラウザ内に保存され、端末間では同期されません。暦は端末の暦を表示し、未設定の帝國暦換算や記念日を生成しません。

## デザイン・アクセシビリティ

象牙色、臙脂、古金、深い森林色を基調に、明朝体、細い二重罫線、紙面を思わせる背景、印章、章ごとの余白で構成しています。スマートフォン表示、キーボードフォーカス、本文へのスキップリンク、ダイアログ内のフォーカス制御、動きを減らす設定、印刷用スタイルを含みます。

## 設定と本文の取り扱い

文藝廳、掲載制度、人物・作品に関する記述は、日ノ本帝國の創作設定を記録するものです。既存の正史に未確認の経歴・受賞歴・制度上の事実を追加しません。設定の確定・変更は、作者の確認を経て行います。

サイトのデザイン・機能を改訂する場合は、各ページの本文と識別情報を保持し、CSS／JavaScript の読み込み順、ページ内アンカー、検索・絞り込み、スマートフォン表示、キーボード操作を確認してください。共有アセットを更新した際は、HTML 内のバージョン付き URL も更新してキャッシュの混在を防ぎます。
